# Questões abertas — não tratar como decisões

| Tema | Pendência |
| --- | --- |
| Identidade | logotipo, tipografia, variações dark e acessível, direitos |
| Licença | MIT, Apache-2.0 ou alternativa; licença dos assets |
| Mapas Android | Google Maps ou outra solução; limites/chaves/custos |
| Offline | cache de lugares versus mapas offline |
| Conta e convites | guest/local, autenticação, compartilhamento |
| Grupo | owner/editor/viewer; exclusão/revogação; registros privados |
| Sincronização | autoria, versionamento e conflitos |
| Pins | links, deduplicação, retenção e remoção da viagem |
| Cofrinho | contribuição pessoal, partilhada e permissões |
| Gastos | moedas, divisão, câmbio e reembolso declarativo |
| Avaliações | visibilidade, fotos, moderação |
| Stamps | registro autoral versus verificação de visita |
| Relógio | seleção por toque obrigatória; giro angular opcional |
| Gestos | detents/snap em dispositivos reais |
| Distribuição | identidades Apple/Android, release e assinatura futuramente |

Decisões devem virar ADRs antes de serem promovidas a requisitos.
