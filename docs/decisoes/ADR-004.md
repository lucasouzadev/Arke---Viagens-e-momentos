# ADR-004 — Cofrinho declarativo

**Data:** 27/10/2026 · **Status:** Aceita para escopo inicial.

## Contexto
Acompanhar quanto poupar para uma viagem sem construir um serviço financeiro.

## Decisão
Registrar metas e contribuições informativas. Não captar depósitos, custodiar ou transferir dinheiro.

## Consequências
UI não deve sugerir saldo de banco. Valores pessoais ficam privados por padrão; funcionalidade regulada requer novo projeto específico.
