# ADR-005 — Documentation-first

**Data:** 27/10/2026 · **Status:** Aceita para a fase atual.

## Contexto
Após explorar design e conceitos técnicos, foi decidido consolidar documentação e publicá-la primeiro.

## Decisão
Manter apenas documentos de produto, design, arquitetura futura e processo. Não publicar Swift/Kotlin, GitHub Actions executável, credenciais ou binários neste marco.

## Consequências
Os próximos PRs devem tratar de refinamento documental e aprovações. A implementação requer autorização e quality gate posterior.
