# ADR-008 — Canário por nome somente no chat de agents

**Data:** 27/10/2026 · **Status:** ACEITA como regra de interação e governança; **valor de tratamento específico ainda não confirmado**.

## Contexto

O responsável quer identificar se um agent cumpriu o protocolo de mensagens de chat observando a presença de seu nome em **toda resposta**. Exige que o nome **jamais** seja incorporado ao código. Como medida de minimização, a restrição se estende a **todos os artefatos persistentes e públicos**: documentação, commits, PRs, logs, comentários, testes e changelog.

## Decisão

- Exigir que **cada resposta visível do agent ao responsável no chat** inclua a forma de tratamento **exatamente como confirmada no chat**, incluindo mensagens de progresso e entrega final.
- O nome é fornecido **somente na sessão de chat**. **Nunca inferir identidade** a partir da conta GitHub, e-mail, perfil, nome de arquivos ou contexto externo.
- **Nunca** copiar o valor para código fonte, configurações, docstrings, logs, arquivos, PRs, commits, templates ou notas públicas. O repositório armazena **apenas a instrução genérica**, sem o valor real.
- Se nome não for confirmado, o agent deve **pedir a forma de tratamento na conversa e sinalizar G-15 bloqueado/não configurado**; não criar falso canário.
- O nome **não é senha, autenticação, prova de leitura das docs nem proteção contra alucinação**. Conferir, separadamente, rastreabilidade de fontes, resultados reais, QA e governança.

## Consequências

Acrescentar [CANARY](../agents/CANARY.md) ao AGENTS e prompt obrigatório; adicionar **G-15** ao QUALITY-GATES e evidência de ausência de dados em artefatos. A regra não altera a interface do app ou mensagens aos usuários finais.

Documentação atual pode avançar com o valor não configurado, mas **G-15 não pode ser declarado aprovado** até confirmação pelo responsável.
